
# SpellForge 🔮

> "맨손으로 마법을 시전한다" — MediaPipe와 OpenCV 기반 실시간 손 제스처 마법 시스템

SpellForge는 웹캠을 마법 시전 인터페이스로 바꾸는 컴퓨터 비전 프로젝트입니다. 컨트롤러도, 버튼도 없이 오직 손만으로 — 방패를 펼치고, 에너지를 충전하고, 파이어볼을 발사하세요. 게임 모드에서는 날아오는 적과 탄환을 손 제스처로 격파합니다.

손 제스처 인식과 실시간 시각 이펙트를 탐구하기 위한 개인 프로젝트입니다.

## 마법 목록

| 제스처 | 마법 | 방법 |
|--------|------|------|
| ✋ 손바닥 펼치기 | **방패 (Shield)** | 손가락을 모두 펴서 카메라를 향해 유지 — 잠시 후 방어막이 활성화됨 |
| ✊ 주먹 쥐기 | **충전 (Charge)** | 주먹을 쥐고 유지 — 황금 오라가 쌓이며 에너지가 저장됨 |
| ☝️ 검지 겨냥 | **파이어볼 (Fireball)** | 검지만 펴서 방향을 겨냥하고 유지 — 손가락이 가리키는 방향으로 발사, 타겟 하나에 명중 후 소멸 |
| ✊ → ☝️ | **메가 파이어볼** | 충전 후 검지로 겨냥 — 반경 150px 내 모든 적을 동시에 폭발시키는 광역 공격 |

### 양손 동시 시전
SpellForge는 양손을 독립적으로 인식합니다. 왼손으로 방패를 유지하면서 오른손으로 충전하고 파이어볼을 발사하는 것이 동시에 가능합니다.

## 게임 모드 — TARGET HUNT

**G 키**를 눌러 게임 로비를 열고, 검지로 게임 카드를 겨냥해 선택합니다.

### 규칙
- 적들이 화면 가장자리에서 중앙을 향해 이동
- 적이 중앙에 도달하면 목숨 -1 (3개 보유)
- 적은 일정 시간마다 **에너지 탄**을 플레이어를 향해 발사
- **파이어볼**로 적을 처치하거나 **방패**로 탄을 막아 점수 획득
- 웨이브가 오를수록 적의 속도와 발사 빈도 증가

### 점수 체계
| 행동 | 점수 |
|------|------|
| 파이어볼로 적 처치 | 10 × 웨이브 |
| 메가 파이어볼로 적 처치 | 20 × 웨이브 (광역) |
| 방패로 탄 막기 | 5 × 웨이브 |

### 키 조작
| 키 | 동작 |
|----|------|
| `G` | 로비 열기 / 게임 종료 |
| `R` | 게임 재시작 |
| `Q` | 프로그램 종료 |

## 동작 원리

SpellForge는 각 제스처마다 **홀드 기반 상태 머신**을 사용합니다. 모든 마법은 자세를 일정 시간 유지해야 발동되며, 이를 통해 손 모양을 바꾸는 도중 실수로 발동되는 오인식을 방지합니다.

```
자세 감지 → 매 프레임마다 카운터 증가
           → 임계값 도달 → 마법 발동
자세 해제  → 카운터 즉시 리셋
```

자세를 전환할 때 (예: 주먹 → 손바닥) 두 카운터가 모두 리셋되어 마법 사이에 항상 자연스러운 공백이 생깁니다.

| 마법 | 감지 조건 | 홀드 시간 |
|------|-----------|-----------|
| 방패 | 손가락 끝의 평균 거리 > 손 크기 × 1.0 | ~0.27초 (8프레임) |
| 충전 | 손가락 끝의 평균 거리 < 손 크기 × 0.78 | ~0.40초 (12프레임) |
| 파이어볼 | 검지 MCP→끝 거리 > 0.9×, 나머지 손가락 < 0.95× | ~0.50초 (15프레임) |

홀드 중에는 충전 아크가 채워지는 시각적 피드백이 제공되어 발동까지 얼마나 남았는지 항상 확인할 수 있습니다.

## 설치 방법

**요구 사항:** Python 3.9 이상, 웹캠

```bash
git clone https://github.com/gundolryan/SpellForge.git
cd SpellForge
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 main.py
```

MediaPipe 손 랜드마크 모델 (~10MB)은 첫 실행 시 자동으로 다운로드됩니다.

### macOS 카메라 권한
웹캠이 열리지 않는 경우, 터미널에 카메라 접근 권한을 부여하세요:  
**시스템 설정 → 개인정보 보호 및 보안 → 카메라**

### macOS 키보드 입력
G, Q 등 단축키는 **OpenCV 화면 창을 클릭해 포커스**한 뒤 사용하세요.  
한글 입력 모드에서도 동작합니다.

## 기술 스택

- [MediaPipe](https://developers.google.com/mediapipe) — 손 랜드마크 감지 (손당 21개 포인트, 30fps)
- [OpenCV](https://opencv.org/) — 웹캠 캡처 및 실시간 렌더링
- Python 3.9+

### MediaPipe Hand Landmarker

MediaPipe는 Google이 개발한 오픈소스 머신러닝 파이프라인 프레임워크입니다. SpellForge는 그 중 **Hand Landmarker** 모델을 사용합니다.

Hand Landmarker는 카메라 프레임에서 손을 감지하고, 손 위의 **21개 랜드마크(keypoint)** 좌표를 실시간으로 추출합니다. 각 랜드마크는 손목, 손가락 관절, 손가락 끝 등 손의 주요 위치를 나타내며, 정규화된 (x, y, z) 좌표로 제공됩니다.

```
손목(0)
  ├── 엄지: MCP(1) → IP(2) → 끝(4)
  ├── 검지: MCP(5) → PIP(6) → DIP(7) → 끝(8)
  ├── 중지: MCP(9) → PIP(10) → DIP(11) → 끝(12)
  ├── 약지: MCP(13) → PIP(14) → DIP(15) → 끝(16)
  └── 새끼: MCP(17) → PIP(18) → DIP(19) → 끝(20)
```

SpellForge는 딥러닝 모델을 직접 다루지 않고, 이 21개 좌표만을 사용해 손 모양을 분류합니다. 손바닥 중심으로부터 각 손가락 끝까지의 거리 비율 또는 MCP→끝 거리를 계산하면 — 별도의 학습 없이도 — 펼친 손, 주먹, 검지 포인팅을 안정적으로 구분할 수 있습니다.
